====================================================
دليل تعديل وتشغيل موقع FLORAL JOY
====================================================

1. هيكل المجلد:
   - index.html          : الصفحة الرئيسية
   - events.html         : صفحة جميع الحفلات (الـ 15 تصنيفاً مع البحث والفلترة والترتيب)
   - event-details.html  : الصفحة الداخلية الديناميكية لكل حفلة وباقاتها
   - ai-planner.html     : صفحة مصمم الحفلات بالذكاء الاصطناعي (AI)
   - portfolio.html      : صفحة سابقة الأعمال
   - about.html          : صفحة من نحن
   - terms.html          : صفحة الشروط والأحكام
   - refund-policy.html  : صفحة سياسة الإلغاء والاسترجاع
   - privacy-policy.html : صفحة سياسة الخصوصية
   - contact.html        : صفحة تواصل معنا
   - css/style.css       : ملف الألوان والخطوط والتنسيق العام
   - js/data.js          : قاعدة بيانات الحفلات الـ 15 وسابقة الأعمال (أسهل مكان لتعديل النصوص والصور)
   - js/main.js          : برمجة الفلاتر، الذكاء الاصطناعي، الشات بوت، والواتساب
   - assets/logo.svg     : الشعار الرسمي للموقع بصيغة متجهة عالية الدقة

2. طريقة التعديل السريع:
   - لتعديل أي حفلة (الاسم، الوصف، الصورة، أو المميزات): افتحي ملف js/data.js وعدّلي النصوص مباشرة.
   - لتغيير الألوان الرئيسية: افتحي أعلى ملف css/style.css وعدّلي متغيرات الألوان داخل :root.
   - لتشغيل الموقع محلياً: اضغطي مرتين على ملف index.html وسيعمل فوراً بكامل الصفحات والأزرار.

- تحسينات التصميم والشعار: تم تحديث شعار الموقع في assets/logo.svg بهوية ذهبية وردية وزمردية متناسقة مع ألوان الواجهة، وإضافة لمسات إطارات وظلال ناعمة في css/style.css.
